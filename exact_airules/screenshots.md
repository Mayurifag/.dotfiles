# Screenshots

## GitHub Screenshots

- When user requests an app screenshot for GitHub, capture it at requested viewport or element bounds.
- Save screenshot as `.webp`; do not use PNG or JPEG.
- Use WebP quality `80` and lossless mode off. Preserve native capture dimensions; do not upscale.
- Save under repo documentation assets, such as `docs/assets/`, unless repo already has another established asset directory.
- Keep screenshot focused on requested app state. Omit browser chrome, unrelated windows, and temporary overlays.
- Verify WebP opens correctly, text remains readable, and file size is reasonable before reporting path.
