# Adding Airules

- Add reusable airules under `exact_airules/`.
- When adding, renaming, or removing an airule, update `dot_config/opencode/AGENTS.md` `## All Airules` in the same change.
- Keep index entries mapped to rendered `~/airules/<name>.md` paths with concise triggers.
- Apply changed airules and `AGENTS.md` with `chezmoi apply`.
