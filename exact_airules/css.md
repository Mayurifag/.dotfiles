# CSS

## Style

- Avoid random gradients, glassmorphism, glows, neon shadows, and colored list-item accent bars.
- Prefer hierarchy, spacing, typography, and contrast to decoration; preserve existing visual language unless redesign
  is requested.

## Structure

- Split stylesheets by component/feature/theme/page; put colors in variables.

## Quality

- Prefer maintainability and rendering performance to novelty; use simple, sufficiently specific selectors, not deep
  chains.
- Use expensive paint effects only when intentional and worth the cost.
