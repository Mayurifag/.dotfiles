# Context7

- Use the Context7 CLI only when requested or when a focused library/API question needs external documentation and
  Context7 is the most practical source. Prefer relevant project evidence and directly available official docs.
- Skip routine edits and general questions. Use a scoped `ctx7 search` with library and version hints when known, reuse
  session results, and stop retrying after a quota error.
- Set `CTX7_TELEMETRY_DISABLED=1` for every CLI invocation.
